# ORchestrate AI — Final Hackathon Prototype

This version adds the requested operational features:
- Emergency case input with priority, duration and surgeon selection
- Surgeon eligibility/resource matching concepts
- OR capability and equipment-aware scheduling (existing scheduler retained)
- Emergency queue
- Multiple demo scenarios
- What-if simulation
- Alternative schedule comparison
- Scheduling objective selector
- Conflict/constraint validation
- OR utilization/bottleneck view
- Why/explainability panel
- Human approval/rejection workflow
- Audit log
- Planning safeguards and duration buffer concept
- Continuous emergency re-optimization demo

## Run
1. Extract the ZIP.
2. Open the `project` folder in VS Code/Cursor.
3. Make sure Node.js LTS is installed.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open `http://localhost:3000`.

The project uses synthetic demo data and is not for clinical use.
